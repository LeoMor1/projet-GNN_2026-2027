       \subsection{Liste d'éléments}
         
      Exemple de liste sans numérotation :
\begin{itemize}
    \item premier item ;
    \item deuxième item ;
    \begin{itemize}
      \item premier sous-item,
      \item second sous-item,
      \item dernier sous-item.
  \end{itemize}
  \item dernier item.
\end{itemize}

Autre liste possible avec numérotation :
\begin{enumerate}
    \item premier item ;
    \item deuxième item ;
    \begin{enumerate}
      \item premier sous-item,
      \item second sous-item,
      \item dernier sous-item.
    \end{enumerate}
  \item dernier item.
\end{enumerate}

\subsection{Tables, Figures}


Les tableaux et figures doivent être centrés horizontalement. Les
légendes sont placées sous ces mêmes éléments et sont centrées si
elle font moins d'une ligne et justifiées sinon. Voir le
tableau~\ref{tab_exemple} et la figure~\ref{fig_exemple} pour des
exemples. Les légendes doivent se terminer avec un point.

\begin{table}[ht]
 \begin{center}
   \begin{tabular}{l | c c }
   \hline
                & modèle 1 & modèle 2 \\
   \hline
   indicateur 1 & 1        & 2        \\
   indicateur 2 & 2        & 1        \\
   indicateur 3 & 1        & 1        \\
   \hline
   \end{tabular}
\caption{Exemple de tableau avec sa légende.} \label{tab_exemple}
 \end{center}
\end{table}


\begin{figure}[t]
\begin{center}

 \caption{Exemple de figure avec sa légende. La légende est centrée,

\end{figure}

   

       \subsection{Equation} \label{sect2:eq}

Pour inclure une équation, vous pouvez utiliser l'environnement \texttt{equation} commue pour l'exemple ci-dessous: 
\begin{equation}
\left(\frac{a^{2} + b^{2}}{c^{3}} \right) = 1 \quad
\mbox{ if } c\neq 0 \mbox{ and if } a,b,c\in \bbbr \enspace .
\end{equation}

    \section{Consignes pour les références} \label{sect3}

Les références sont données en fin de rapport.

Nous vous recommandons l'utilisation de
\textsc{Bib}\TeX\ avec le style bibliographique \textit{splncs03.bst}. Par exemple pour ce document, nous utilisons le fichier \texttt{bibM2.bib}, dans lequel est présent la référence \cite{Russell2003}. 
     
Dans le corps du texte, on utilise la commande \texttt{$\backslash$ cite} pour faire référence à un article.

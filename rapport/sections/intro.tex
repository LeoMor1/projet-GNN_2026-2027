\section{Introduction}
\label{sec:intro}

Le graphe étudié relie 3363 aéroports par 13547 liaisons non orientées ; chaque nœud a une latitude, une longitude, la population de sa ville, un nom de ville et un pays. Une partie de ces informations est fausse, et certains liens aussi. Nous comparons ce qu'un modèle prédit à ce qui est observé et regardons où les deux divergent le plus, selon trois volets : les liens (GAE, VGAE), puis les nœuds (GCN, GAT) pour les pays, positions et populations erronés. Code : \url{https://github.com/LeoMor1/projet-GNN_2026-2027}.

\begin{abstract}
% TODO : abstract commun, à réécrire quand les trois parties sont terminées.
We look for erroneous links in an airport network (3363 nodes, 13547 edges) with graph autoencoders.
Since the data has no link labels, we inject random false edges at rates between 1\% and 20\% and rank every edge by $1-p_{ij}$, where $p_{ij}$ is the decoder's reconstruction probability.
A GAE and a VGAE reach an AUC of 0.92--0.94, with no clear difference between them.
Adamic--Adar, which needs no training, has a higher AUC at every rate; the autoencoders only keep an edge in average precision when anomalies are rare.
On the original graph, the top-ranked edges are mostly long but plausible routes, and one of them points to a node with wrong coordinates.
Code: \url{https://github.com/LeoMor1/projet-GNN_2026-2027}.
\begin{keywords}
Graph neural networks, graph autoencoder, link anomaly detection
\end{keywords}
\end{abstract}

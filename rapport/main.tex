\begin{abstract}
% TODO : abstract commun, à réécrire quand les trois parties sont terminées.
We study link and node anomaly detection in a network of 3,363 airports and 13,547 edges. Using synthetic corruptions, we compare graph neural networks with simple baselines. Adamic–Adar achieves the best link AUC, while GAE/VGAE improve average precision for rare anomalies. DOMINANT mainly detects geographic errors, whereas GAT identifies corrupted population values. These results highlight the importance of feature preprocessing and the limitations of synthetic evaluation.
Code: \url{https://github.com/LeoMor1/projet-GNN_2026-2027}.
\begin{keywords}
Graph neural networks, graph autoencoder, link anomaly detection
\end{keywords}
\end{abstract}
